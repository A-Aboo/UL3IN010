# TME 1 - Rappel C

Ce TME contient :

- Un programme qui calcule le maximum d'une liste d'entiers passée en arguments.
- Des fonctions de manipulation de tableaux :
  - initialisation aléatoire
  - affichage
  - somme
  - minimum et somme
- Allocation d'un tableau sur la pile et dans le tas.
- Observation de la mémoire avec `getrusage`.
